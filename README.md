## 3. Mục tiêu
•	Tổ chức file và thư mục khoa học.
•	Chia sẻ tài liệu và thiết lập quyền truy cập phù hợp.
•	Tìm kiếm, lựa chọn và đánh giá thông tin trên Internet.
•	Nhận biết đạo văn, biết paraphrase và ghi nguồn.
•	Nhận biết các nguy cơ an toàn số phổ biến.
•	Sử dụng Google Workspace để cộng tác.
•	Làm quen với GitHub ở mức cơ bản, không yêu cầu code.
•	Sử dụng ChatGPT/Gemini/Copilot và NotebookLM có trách nhiệm.
•	Rèn luyện làm việc nhóm, trình bày và phản biện.
